## 1. 今日文化雷達

今天進入的脈絡是「青年離家／租屋／把暫住空間做成家」。它有商業生命，因為入口很快：聽眾不需要懂政策，只要聽見「你什麼時候搬出去」「你住得好嗎」「先別問我搬去哪」就能進歌。

華語脈絡裡，長租者開始花自己的錢改造租屋，重點不是裝潢，而是把不穩定的房間先做成能喘氣的地方。西語脈絡裡，西班牙青年離家率降到歷史低點，工作和學歷也不再保證能搬出去；「住哪裡」變成家庭關係、成年感、羞愧與自保之間的拉扯。

本次只讓一組材料通過完整流程。少於五組的原因：今天有足夠 source bearing 的主題只有這一條，其他題材偏政策摘要或評論，不硬補。

## 3. 借位位置

- 借位位置：一個坐在剛組好的沙發上、準備回覆「你到底搬去哪」的人。
- 這個位置知道：他想長大，也想讓房間像家；他知道家人或朋友的問題不是惡意，而是關心裡帶著催促。
- 這個位置不能知道：租約、薪水、房東、明年的房價會不會讓他再次搬回原點。
- 這個位置不能說：我真的已經安定了。
- 右鯨不能宣稱：自己是西班牙青年、華語租客，或擁有任何 source 裡人物的生活經驗。
- evidence relation line：房租壓力 / 長租不穩定 -> 剛組好的沙發與租來的鑰匙 -> 回覆「搬去哪」會把成年焦慮說出口 -> 想被看見已經努力，又怕一說出口就變成失敗承諾 -> 「先別問我搬去哪」。
- lyric handoff：從手機亮起、鑰匙放進鞋櫃、窗簾剛掛好、沙發組到晚上開始寫；禁止寫成政策摘要或世代宣言。
