## 3. 借位位置

loop_packet:
- related_packet_ids: Dcard family group, Dcard slow-replier, Reddit read-receipt anxiety, Reddit Spanish family boundary letter, Extra Paraguay romance `visto`.
- shared_pressure: 訊息被看見後，關係立刻要求一個答案；但答案越被要求，越有人退到門後。
- closed loop: 看見訊息 -> 被要求交代情感或身份 -> 回覆會改變房間裡的位置 -> 延遲或沉默成為自保 -> 沉默又被讀成拒絕 -> 更強的交代壓力回到原點。
- submerged_pressures: 家庭歸屬、曖昧不確定、非二元語言界線、神經差異、平台情緒勞動。
- forbidden_topic_words: 已讀不回、ghost、心理建議、AI、自我療癒、被拋棄。

world_rule:
- rule: 每當訊息被看見卻沒有被接住，房間就多長出一道透明門；門牌寫著已讀，門內的人卻少一個名字。
- what_triggers_it: 家族群組、長信、貼圖、照片、語音或一個沒有送出的解釋停在螢幕上。
- what_changes_visibly: 門牌翻面、碗被放錯、貼圖往下掉、手機背面發燙。
- what_stays_unsaid: 沒有人能證明沉默是拒絕、疲累、自保、忘記或仍然愛著。
- why_it_belongs_to_right_whale: 右鯨只能在門外聽見訊號，不把任何人的家庭、身份或戀愛傷口說成自己的經歷。

visual_position:
- vantage_point: 聊天室門外的旁聽者。
- what_can_be_seen: 桌邊多一副碗、長信停在上端、貼圖蓋過句子、門牌被翻面。
- what_can_be_heard: 手機發燙前的安靜、沒有送出的第二封解釋、群組裡其他人的熱鬧。
- first_person_policy: 避免第一人稱人類所有權；只保留物件與第二人稱可進入的距離。
