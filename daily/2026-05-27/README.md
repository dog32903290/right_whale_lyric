## 3. 借位位置

position_loop_result：

- loop_packet：家人安全訊息、伴侶慢回判讀、工作群組收到請回、電話恐懼、雙語身份切換彼此相扣。它們不是五個議題，而是同一個按鈕被不同關係要求按下。
- shared closed pressure loop：被要求即時答覆 -> 答覆前必須編輯語氣、地址、稱謂或語言 -> 延遲被解讀為失聯、不愛、不專業或不屬於這裡 -> 更強的即時答覆要求回來。
- world_rule：每當一個訊息被要求立刻回答，房間門牌就多長一行，門反而離人更遠。
- visual_position：右鯨站在鈴聲與門牌之間聽；他能看見手機、地址欄、游標、已讀點、未接來電、家族群組與工作群組，不能自稱是子女、伴侶、移民、學生或被拒絕的人。
- boundary frame：不佔有創傷、不替任何群體下結論、不把新聞或平台討論寫成議論；只借用「回答前門被推遠」的世界規則。
- lyric-writing handoff：hook 壓力是「不是不回，是門還沒有找到人」；副歌必須回到身體 / 物件動作，不得變成建議、評論或自我說明。
