## 3. 借位位置

loop packet:

- shared pressure: 家族、語言社群、移民家庭、AI companion 和 voice technology 都要求人交出一個可以被接收的聲音；聲音一旦被修到合格，原本要說的話反而退到後面。
- loop nodes: 家族群組三個點亮起、語音重錄四遍、口音/音節被圈起、AI chat 給出穩定肯定、voice candidate 被預聽、送出鍵先亮起。
- false exit: 先送出一段聽起來順的聲音，好像能通過；但每次通過都讓下一次更需要被修正。
- return pressure: 下一個群組訊息、下一次家庭問題、下一個語言場合、下一個 AI 回覆或 voice preview 又要求聲音先抵達。

world rule:

每當一個聲音先被要求通過，房間就會生成一個更好聽的版本坐下來；版本越穩，本人越晚被聽見。

visual position:

右鯨站在手機語音預覽、家族群組、語言練習紙、AI companion chat window 和 voice candidate list 旁邊，看播放條爬到第七秒，送出鍵亮著，拇指停住。右鯨不能說自己是受催婚者、No sabo speaker、移民家庭孩子、AI companion user 或 AAC user；他只能唱「聲音被送出以前，那個人還在第七秒」。

lyric-writing handoff:

- allowed objects: 麥克風、播放條、波形、第七秒、送出鍵、群組三個點、紅點、被圈起的音節、練習句、空椅子、半段音檔。
- forbidden claims: 不寫政策評論、不寫身份口號、不把移民/語言/AI 關係經驗變成右鯨第一人稱、不寫 therapy slogan 或安撫式命令。
- hook pressure: 第七秒停住；聲音還沒能照原樣送出。
