## 3. 借位位置

loop packet:

- shared pressure: 家庭、租屋、婚姻、工作語言和聲音系統都要求人先填好一個可被提交的位置；但生活條件、關係語句和聲音都還沒有真正抵達。
- loop nodes: 現居地址欄閃爍、匯款欄亮著、婚房圖紙壓住餐具、父母訊息跳出、房租訊息被延後、預聽鍵按到一半、鑰匙回到桌角。
- false exit: 先填一個答案、先匯一筆、先發一個聲音好像能通過，但每一次提交都讓下一格更早出現。
- return pressure: 下一張表、下一餐、下一個會議、下一個房租訊息又要求位置被提前說清楚。

world rule:

每當一個地址還沒長出可以住下的空間，表格就先要求它被送出；越接近送出，桌上的碗、鑰匙和聲音越退回原位。

visual position:

右鯨站在租屋表格、餐桌、婚房圖紙、轉帳欄和 voice preview 旁邊，看手指按住送出、預聽停在半路、鑰匙躺回桌角。右鯨不能說自己是租屋青年、女兒、移民、AAC 使用者或任何 source 裡的人；他只能唱那一格還不能被提交的距離。

lyric-writing handoff:

- allowed objects: 現居地址欄、游標、匯款欄、碗、湯匙、婚房圖紙、房租訊息、預聽鍵、聲音、鑰匙、桌角。
- forbidden claims: 不寫政策評論、不寫世代檄文、不把語言或聲音寫成身份口號、不使用創傷所有權或第一人稱冒領。
- hook pressure: 現居地址還沒填好。
