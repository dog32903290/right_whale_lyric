# Daily Archive

每日資料夾使用日期命名：

```text
YYYY-MM-DD/
  README.md
  lyrics.md
```

## README.md

公開工作記錄。它回答三件事：

1. 今天右鯨進入了哪個華語 / 西語 / 跨語衝突。
2. 哪些 source 有承重，哪些被丟掉。
3. 哪一組三語歌詞最值得繼續做 demo / melody / revision。

## lyrics.md

乾淨歌詞。只保留：

- 歌名或 hook
- 中文
- English
- Español

如果某天只有部分候選通過 QC，`lyrics.md` 只放通過的歌詞；數量不足的原因寫在當天的 `README.md`。
