# right_whale_lyric

右鯨每日借位歌詞公開歸檔。

這個 repo 放的是給人看的結果，不是工具暫存區。每天的資料在 `daily/YYYY-MM-DD/`，一個日期只放兩份主要文件：

- `README.md`：今天怎麼找題、怎麼借位、哪些素材通過或被丟掉、最後推薦哪一首繼續做。
- `lyrics.md`：乾淨歌詞，只放標題、語言標籤、歌詞正文。

## 閱讀方式

從 [`daily/`](daily/) 進去，選日期。每個日期資料夾的 `README.md` 會先說明今日題目與路徑，再連到同一資料夾裡的 `lyrics.md`。

## 公開規則

- 不放 raw agent trace、prompt、私密推理或工具噪音。
- 不全文搬運新聞、文章或他人歌詞。
- source 只保留可追溯 URL 與整理後的承重摘要。
- `lyrics.md` 不放 QC、來源、推薦理由或製作說明。
